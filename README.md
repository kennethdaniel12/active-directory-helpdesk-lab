# Active Directory Help Desk Lab

## Overview

This project is a hands-on IT support lab designed to simulate common Tier 1 Help Desk tasks.

I built and administered a Windows Active Directory environment hosted in AWS and used it to practice user management, security groups, computer management, permissions, troubleshooting, and help desk ticket documentation.

## Environment

* AWS EC2
* Windows Server
* Active Directory Domain Services
* Windows DNS
* Windows Client
* Remote Desktop Protocol (RDP)

## Skills Demonstrated

* Active Directory user management
* Password resets
* Account lockout troubleshooting
* Security group management
* Organizational Units
* Computer/domain management
* Basic permissions management
* Windows administration
* Help Desk troubleshooting
* Ticket documentation

## Help Desk Scenarios

| Ticket | Scenario             |
| ------ | -------------------- |

| 002    | Password Reset       |

| 004    | Shared Folder Access |
| 005    | Employee Offboarding |
| 006    | Domain Join          |
| 007    | Department Transfer  |
| 008    | Disabled Account     |

## Project Goal

The goal of this project was to gain practical experience performing and documenting common tasks associated with an entry-level IT Help Desk role.
